## Label taxonomy (§3)

- **AUTHORITATIVE / OBSERVED** — 18 COOLR high-confidence Meghalaya points (day precision, ≤5 km).
- **PSEUDO-BACKGROUND, tabular** — 36 `BG_*` rows: sampled locations with no COOLR record
  (NOT confirmed absence). Strategy inherited from package; distances to nearest event
  recorded in `experiment_gs_v1.json` groups; label noise possible near unreported slides.
- **PSEUDO-BACKGROUND, temporal** — 648 `BG_<loc>__<event>` windows: 36 locations × 18 event
  times (share event weather; split by event, never by row).
- **UNLABELED** — gauges, SRTM, soil, OSM, ECMWF samples (predictors / schema only).
- **HELD-OUT (blind)** — 20 lower-confidence Meghalaya COOLR events; never trained on.

## Spatial / temporal alignment

- Common CRS for modelling: **EPSG:4326**. Boundary file is EPSG:7755 (converted on use).
- RF points, Mamba windows, gauges, SRTM, soil all overlap Meghalaya; east fringe
  (lon 92–93) lacks SRTM; gauges end 2018 (daily) / 2023–2025 (hourly, spiky).
- Mamba features are ERA5 reanalysis (modelled, 0.25°), gauges are observed — kept as
  separate lineages with provenance tags; never silently mixed.
- No resampling of categorical LULC; LULC codes kept opaque (codebook missing).

## What this audit blocks

SegFormer training (void imagery, no masks); SAR features (no S1 scenes in `datasets/`);
"real-time" claims (Jan-2020 samples only); production-accuracy claims (n=18 positives).
